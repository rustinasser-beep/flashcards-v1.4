# Flashcards v1.4.3

## التحديثات في 1.4.3
- تحسين نظام "حفظني": أولوية أعلى للكلمات الصعبة، تباعد تدريجي للكلمات المتقنة (mastery/difficulty/consecutive tracking)، وملخص جلسة مفصّل.
- منع الإجابة المزدوجة (double submit) في كل أنواع الاختبارات عبر قفل السؤال (testLocked / processing) وتوكن سؤال (questionToken) يتجاهل نتائج الصوت القديمة.
- TTS: نطق إنجليزي فقط، مع انتظار تحميل الأصوات (voiceschanged) وعدم استخدام صوت عربي كبديل.
- Speech Recognition: تحديد لغة التعرف تلقائيًا حسب لغة الإجابة المطلوبة (en-US / ar-SA) لا حسب اتجاه البطاقة فقط.
- إصلاح تغيّر خلفية الحقول (input) بسبب Autofill أو حالة :invalid في المتصفح، بدون تغيير الشكل الحالي.
- Service Worker: كاش جديد (v1.4.3) واستراتيجية network-first لصفحة index.html لمنع تعليق نسخة قديمة.
- تحديث ثابت الإصدار وترقيم أماكن ظهوره (index.html, README, sw.js).

## الملفات
- `index.html` الواجهة.
- `style.css` الشكل.
- `script.js` كل منطق التطبيق.
- `manifest.json` تثبيت التطبيق كـ PWA.
- `sw.js` تشغيل Offline على GitHub Pages.
- `icons/` أيقونات محلية بدون روابط Placeholder خارجية.

## التشغيل على GitHub Pages
ارفع الملفات كما هي إلى نفس مجلد الموقع، وتأكد أن `index.html` في جذر GitHub Pages.

لا توجد حاجة إلى Firebase لتشغيل الكلمات أو الحفظ أو الاختبارات. البيانات الأساسية محفوظة في `localStorage` على جهاز المستخدم.

## ملاحظة الصوت
اختبار الصوت يستخدم Web Speech API، لذلك دعمه يعتمد على المتصفح والميكروفون. Chrome وEdge عادةً أفضل من غيرهما لهذه الميزة.
